# Monster Reveal Component

Interactive "Reveal your monsters!" Framer-style character showcase component inspired by @ersharium.

## Features
- **Two-layer architecture**: Top drafting/sketch layer and bottom full-color artwork
- **Realtime Liquid Hole**: HTML5 Canvas cutout (`destination-out`) with surface tension wobble
- **3D Pop-up**: Perspective pop-up (`scale`, `rotateX`, `translateY`) on monster torso hover
- **Zero dependencies**: Pure vanilla HTML5, CSS3, and JavaScript

## Run
```bash
python3 -m http.server 3000
```
Open `http://localhost:3000/monster-reveal/index.html`.
